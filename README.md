# Práctica de Python: Estadísticas de notas

## 1. Descripción del proyecto

Este proyecto consiste en crear un programa en Python que analiza una lista de notas y calcula diferentes estadísticas utilizando funciones integradas del lenguaje.

El objetivo es aprender a trabajar con listas, realizar operaciones matemáticas y comprobar condiciones mediante funciones de Python.

## 2. Funciones de Python utilizadas

En esta práctica he utilizado las siguientes funciones:

- `max()`: obtiene el valor más alto de una lista.
- `min()`: obtiene el valor más bajo de una lista.
- `sum()`: suma todos los valores de una lista.
- `len()`: devuelve la cantidad de elementos de una lista.
- `any()`: comprueba si al menos un elemento cumple una condición.
- `all()`: comprueba si todos los elementos cumplen una condición.

También he aprendido a calcular la media dividiendo la suma de las notas entre la cantidad de elementos:

`sum(notas) / len(notas)`

## 3. Comandos de Git utilizados

Durante la práctica he utilizado Git para controlar las versiones del proyecto y publicarlo en GitHub.

| Comando | Función |
|---|---|
| `git init` | Inicializa un repositorio Git en la carpeta del proyecto. |
| `git branch -M main` | Establece el nombre de la rama principal como `main`. |
| `git add` | Añade archivos a la preparación del próximo commit. |
| `git commit` | Guarda una versión del proyecto en el historial. |
| `git remote add origin` | Vincula el repositorio local con el repositorio de GitHub. |
| `git push -u origin main` | Sube los cambios a GitHub y establece la rama remota de seguimiento. |

## 4. Conocimientos adquiridos

Con esta práctica he aprendido a:

- Crear y utilizar listas en Python.
- Calcular estadísticas mediante funciones integradas.
- Utilizar condiciones con `any()` y `all()`.
- Comprender la diferencia entre comprobar si al menos un elemento cumple una condición y comprobar si todos la cumplen.
- Utilizar Git para guardar versiones de un proyecto.
- Crear un repositorio en GitHub y publicar archivos mediante Git.

## 5. Resultado final

El programa analiza siete notas y muestra la nota más alta, la más baja, la suma, la cantidad de notas, la media y dos comprobaciones adicionales.
